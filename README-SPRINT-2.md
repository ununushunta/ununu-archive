# ununu Archive — Sprint 2

This bundle replaces the default Next.js screen with the first production implementation of the archive UI.

Included:

- Desktop Finder-like project list
- Collapsible desktop sidebar
- Mobile accordion project list
- EN / JP language switching
- Project hero, logo, title, overview, tags and stills placeholders
- About page shell
- ununu header logo
- Local mock data ready to be replaced by Sanity in a later sprint

## Install

Copy the contents of this bundle into the root of your local `ununu-archive` project and replace existing files when prompted.

Then run:

```bash
npm run dev
```

Before pushing:

```bash
npm run build
```
